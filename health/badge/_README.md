# depmedic health badges

Static SVGs, regenerated by `tools/build-health-badges.mjs` whenever
`data.json` is rebuilt by `tools/build-health-pages.mjs` (nightly).

Embed:

```
![depmedic health](https://depmedicdev-byte.github.io/health/badge/<package>.svg)
```

Want a badge for a package not in the snapshot? Open an issue on
depmedicdev-byte/depmedicdev-byte.github.io and we'll add it to the
nightly seed list. (For self-serve, the Org Dep Health Monitor at $19/mo
publishes badges for any package in your repos.)
