If you bought the Senior Dev Cursor Rules pack

The ZIP has two folders: rules/ and prompts/. The fastest way to wire it up:

  1. Copy rules/00-core.cursorrules to your repo as .cursorrules.
  2. Append the stack-specific file (e.g. 02-react-modern.cursorrules) to the same file.
  3. For Claude Code or ChatGPT, drop prompts/senior-dev-system.md into the system prompt slot.

Each .cursorrules file is independent. Mix and match the overlays that match your stack; delete the rest.

If you bought the Senior Dev System Prompt

The ZIP has one file you'll use: senior-dev-system.md. Paste the entire file into the system prompt slot of whatever tool you're using - Cursor's "Rules for AI", Claude's system message, ChatGPT's custom instructions, or your local LLM's system prompt.

The USAGE.md in the same folder explains the few knobs (review tone, refactor scope, comment policy) you can tune.

If you bought the Hardened Workflows Pack

The ZIP unpacks into one folder with five drop-in workflow templates:

  • node-library.yml - npm packages with OIDC publishing.
  • node-app.yml - web apps with build/deploy split.
  • python-library.yml - PyPI publish via Trusted Publishing.
  • monorepo-affected.yml - pnpm + turbo with affected detection.
  • release-please.yml - Conventional Commits to semver releases.

Each template has 4 # CUSTOMIZE markers - find them, edit them, commit. Then read permissions-cheatsheet.md and oidc-setup.md to understand the security defaults.

Verify your edits didn't introduce any smells: 

npx ci-doctor .github/workflows/your-template.yml
